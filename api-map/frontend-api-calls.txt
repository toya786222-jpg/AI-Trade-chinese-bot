============================================
LICENSE SYSTEM
============================================

1. VALIDATE LICENSE KEY
   File: src/lib/license.ts
   Function: activateLicense(key)
   Flow:
     1. Client validates format: /^[A-Z0-9]{4}-[A-Z0-9]{4}-[A-Z0-9]{4}-[A-Z0-9]{4}$/
     2. Get device ID from localStorage or generate new
     3. Call Supabase RPC: validate_license(p_key, p_device_id)
     4. Store key + tier in localStorage
   Storage Keys:
     - cs_licence_key → License key string
     - cs_licence_tier → Tier (standard/pro/pro_max)
     - cs_device_id → UUID device identifier

2. VERIFY LICENSE (on page load)
   File: src/lib/license.ts
   Function: verifyLicense()
   Flow:
     1. Read key from localStorage
     2. If no key → return false
     3. Call Supabase RPC: validate_license(p_key, p_device_id)
     4. If invalid → clear localStorage, return false
     5. If valid → return true

3. GET STORED TIER
   File: src/lib/license.ts
   Function: getStoredTier()
   Returns: "standard" | "pro" | "pro_max"

============================================
LICENSE MANAGEMENT (Admin)
============================================

11. GET ALL LICENSES
    Function: supabase.from('licenses').select('*').order('created_at', { ascending: false })
    Response: { data: License[], error }
    Table columns: id, license_key, user_name, tier, status, expiry_date, device_ids, device_limit, activated_at, last_active_device, last_active_at, created_at

12. CREATE LICENSE
    Function: supabase.from('licenses').insert({
      license_key: "XXXX-XXXX-XXXX-XXXX",
      user_name: "string",
      device_limit: 1|2|5|10|0,
      expiry_date: "ISO_DATE" | null,
      status: "active"
    })
    Response: { error }
    Used in: Admin panel "Create New License"

13. UPDATE LICENSE
    Function: supabase.from('licenses').update(data).eq('id', licenseId)
    Data options:
      - { tier: "pro_max" }  → Upgrade
      - { tier: "standard" } → Downgrade
      - { status: "active" } → Activate
      - { status: "expired" } → Deactivate
      - { status: "blocked" } → Block
      - { device_ids: [] } → Reset devices
    Response: { error }

14. DELETE LICENSE
    Function: supabase.from('licenses').delete().eq('id', licenseId)
    Response: { error }
